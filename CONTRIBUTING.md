# Contributing

Baochip is in an early research phase. Issues that sharpen the threat model, compare prior art, identify ambiguous claims, or propose falsifiable experiments are especially useful.

Before proposing implementation work:

1. State the security property or research question.
2. Identify the relevant trust boundary and adversary.
3. Separate assumptions from claims.
4. Define how the proposal could fail and how it would be tested.
5. Avoid production, certification, or novelty claims without evidence.

Please keep commits focused and document any generated artifacts and tool versions.
